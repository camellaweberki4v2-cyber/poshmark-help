# Order update — FormSubmit

Статическая HTML-форма. Node.js и сборка не требуются.

## Публикация через GitHub и Vercel

1. Создайте репозиторий на GitHub (можно Private).
2. Через Add file → Upload files загрузите index.html и vercel.json в корень репозитория и сохраните изменения.
3. В Vercel выберите Add New → Project и импортируйте этот репозиторий.
4. Framework Preset: Other. Root Directory: ./ . Build Command: не требуется. Output Directory: . (задаётся в vercel.json).
5. Нажмите Deploy и откройте выданный адрес https://имя-проекта.vercel.app.
6. Отправьте форму с опубликованной страницы. Если FormSubmit попросит подтверждение нового адреса, подтвердите его в письме.

В письме ожидается реальный адрес опубликованной формы. Подстановка poshmark.com удалена; окончательный результат проверяется новым письмом после публикации.

## Получатель

Адрес получателя задаётся переменной TO в index.html. Сейчас сохранён прежний адрес.
Он виден посетителям в исходном коде страницы, даже если репозиторий приватный.
Не размещайте в HTML пароли, SMTP-ключи или другие секреты.

## Локальный запуск

python -m http.server 8000 --bind 127.0.0.1

Откройте http://127.0.0.1:8000/ . При локальной отправке в письме может отображаться локальный адрес.
